# Reproduced experiment artifacts (original runs)

The CSVs and model weights in this folder are copied from the uploaded completed project. They have **not** been regenerated during GitHub packaging.

- 108 main training histories (`*_training.csv`) from 1000 episodes each.
- 108 pre-trained checkpoints for all main map / mouse / reward / algorithm / seed combinations.
- `evaluation_summary.csv`: 108 evaluated models, 100 evaluation episodes each.
- `aggregate_summary.csv`: 36 grouped configurations (mean and sample SD across 3 seeds).
- `tuning/hyperparameter_trials.csv`: 48 tuning trials from 350-episode training, 50 evaluation episodes each.
- `learning_curves.png`: original figure generated by the main training run.
- `run_metadata.json`: recorded run configuration and basic machine information.

**Do not confuse the 350-episode tuning sweep with the 1000-episode main experiment.** Use `--out` to keep future experiment runs in a different folder.
